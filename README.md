# Guess The Number

A native Android number guessing game built with Kotlin and Jetpack Compose.

## Features
- Modern Jetpack Compose UI
- Number guessing gameplay
- Android support from API 24

## Build
Build the debug APK using:

```bash
gradle :app:assembleDebug
